# 🌱 Moody - My Mood Tracker App

I built this app to track my mood and write journal entries. It’s personal, simple, and looks different from most apps.

---

## 🤔 What is this app?

This is a mood journal. You pick how you feel, write a few sentences, and save it. Over time, you can look back at your entries and see patterns.

## 🧠 Why did I build it?

I wanted to make something useful for myself. I also wanted to learn how to build a full app from start to finish — from login to database to deployment.

---

## 🛠️ What technologies did I use?

- **React** – for building the user interface
- **Supabase** – for login, signup, and storing data
- **Vercel** – for hosting the app online
- **CSS** – all styles are custom, no libraries

No Tailwind. No Bootstrap. Just pure CSS.

---

## 🎨 What makes it look different?

I used a design style called **Brutalism**. It’s bold, minimal, and uses thick borders, sharp edges, and a single accent color (yellow). No rounded corners. No glassmorphism.

---

## 📦 What can users do?

- Create an account
- Log in
- Pick a mood from 10 emojis
- Write a journal entry
- See all past entries
- Delete entries
- Change their name in settings
- Log out

---

## 🗄️ How is data stored?

I used Supabase. It’s a backend-as-a-service that gives me:
- Authentication
- A PostgreSQL database
- Row Level Security (so users only see their own data)

---

## 🌍 Where is it hosted?

I deployed it on Vercel. It’s live and accessible from any device.

---

---

## 🧪 What challenges did I face?

- Setting up authentication correctly
- Connecting Supabase with React
- Fixing permission errors (403)
- Deploying to Vercel with environment variables

---

## 💡 What did I learn?

- How authentication works in real apps
- How to manage state in React
- How to structure a full project
- How to deploy and make it live
