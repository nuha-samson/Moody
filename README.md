# 🌱 Moody - Mood Tracker & Journal

A beautiful, minimalist mood tracking and journaling app with a modern brutalist design. Built with React, Supabase, and pure CSS.

![Moody App Screenshot](https://via.placeholder.com/1200x630/1a1a1a/ffb81e?text=Moody+Tracker)

## ✨ Features

-  **Mood Tracking** - Choose from 10 different moods
-  **Journal Writing** - Write your thoughts and feelings
-  **History View** - See all your past entries
-  **Secure Authentication** - Email verification with 30-day session
-  **Cloud Sync** - All data stored in Supabase
-  **Fully Responsive** - Works on desktop, tablet, and mobile
-  **Brutalist Design** - Bold, minimal, and memorable

##  Tech Stack

| Technology | Purpose |
|------------|---------|
| **React 19** | Frontend framework |
| **React Router** | Navigation & routing |
| **Supabase** | Authentication & PostgreSQL database |
| **Vite** | Build tool & development server |
| **Vercel** | Hosting & deployment |
| **CSS** | Styling (no frameworks!) |
