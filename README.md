# Moody 

Moody is a mood tracking and journaling application designed to help users record their daily moods and reflect on their experiences over time.

##  Features

*  User registration and authentication
*  Track daily moods using 10 mood options
*  Create and manage journal entries
*  View previous mood entries
*  Delete journal entries
*  Manage user profile information
*  Securely log out of the application

##  Project Goal

The goal of Moody is to provide a simple and personal space for users to record their moods and journal entries while practicing full-stack application development.

The project focuses on building a complete application with a React frontend, RESTful backend API, database persistence, and user authentication.

##  Future Improvements

*  Mood trends and analytics
*  Visual mood statistics
*  Daily mood reminders
*  Search and filter journal entries
*  Calendar-based mood tracking
*  Additional mood and journal customization options
